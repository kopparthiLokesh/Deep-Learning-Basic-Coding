# 🧠 Deep Learning Basic Coding

A collection of fundamental Deep Learning implementations covering Artificial Neural Networks (ANN), Convolutional Neural Networks (CNN), Natural Language Processing (NLP), transfer learning, and data preprocessing using TensorFlow, Keras, and Python.

---

# 📌 Repository Overview

This repository contains beginner-friendly notebooks that demonstrate the core concepts of Deep Learning through practical implementations. It serves as a learning resource for understanding neural networks, computer vision, NLP, and data preprocessing techniques.
